# base64 runs on base64-codec

The base64 crate gave way to base64-codec 0.1 (`alloc`), as the family decided on 2026-11-03: src/output.rs encodes the `data` field of `Bytes` through `Base64Codec::default().encode_vec`, standard alphabet and padded as before, so the JSON shape is unchanged. The codec reads the CPU token the binary installed (`SimdCpu::install_detected` in its `main`), the portable baseline otherwise; the library itself never detects. base64-codec needs Rust 1.89, now the crate's minimum. With this, io-pim-discovery's tree holds no base64 crate once it takes the release carrying it.

Capabilities moved: none.

Verified: `cargo clippy --all-features --all-targets` and `cargo clippy --no-default-features --features terminal` clean, `cargo test --all-features` passed (37, `bytes_print_as_base64_with_their_size` among them), `cargo tree -i base64` finds no package.
